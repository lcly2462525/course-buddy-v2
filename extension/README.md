# Course Buddy 浏览器扩展

在交大 Canvas 回放页**一键下载语音转录 + AI 生成笔记**。跑在你已登录的浏览器里，
**不开任何网络端口、不装 Python、跨系统**（Windows / macOS / Linux 的 Chrome、Edge 都能用）。

它是 `course-buddy-v2` CLI 的浏览器移植版。最大好处：因为扩展本身就在你登录着的
浏览器里发请求，原来 CLI 版最头疼的 **cookie 过期 / 读不出来** 问题**直接消失**。

---

## 一、安装（开发者模式，先本地试用）

1. 打开 Chrome / Edge，地址栏输入 `chrome://extensions`（Edge 是 `edge://extensions`）
2. 打开右上角 **开发者模式**
3. 点 **加载已解压的扩展程序**，选中本 `extension/` 文件夹
4. 扩展出现在工具栏。点它 → 右上角图标 → 打开设置页，填 **LLM API Key**（不生成笔记、只下转录的话可跳过）

> 以后要给别人用、且想要"一键安装无技术含量"，就把这个文件夹打包上传到
> Chrome 应用商店，选 **不公开(unlisted)** 发布，别人拿链接点"添加至 Chrome"即可。

---

## 二、用法

**方式 A：在 Canvas 页面上直接选（推荐，支持多选）**
打开任意 `oc.sjtu.edu.cn/courses/<课程>` 页面，右下角点 **📝 Course Buddy** 展开面板：
1. 点 **载入回放清单**
2. 用快捷按钮一键选：`最新一讲` / `最近3讲` / `最近5讲` / `最近两周` / `最近一月` / `全部` / `清空`；也可手动勾选任意几讲
3. 点 **⬇ 下载转录** 或 **📝 生成笔记**，批量处理，逐讲显示进度（只认证一次）

**方式 B：点工具栏扩展图标（快速处理单讲）**
- 在课程页会自动填课程 ID；点 **列回放** 选某一讲 → **下载转录** / **生成笔记**

生成的文件通过浏览器"下载"保存到你的下载目录：
- 转录：`日期_课程(第N讲).txt`
- 笔记：`日期_课程(第N讲).md`

---

## 三、两类用户对应关系

- **只要忠实转录、自己喂 AI** → 用"下载转录"，拿到带时间戳的纯文本 `.txt`，完全不碰 LLM。
- **要省事、直接出笔记** → 配一次 API Key，用"生成笔记"。

---

## 四、已知限制 / 待办

- **认证前提**：你得先在这个浏览器里登录过 `oc.sjtu.edu.cn`。没登录会提示去登录。
- **生成耗时**：一讲约 1–3 分钟。生成期间别关弹窗（页面按钮方式可以关，后台会继续）。
- **service worker 5 分钟上限**：极长的课（>40 分钟且分片很多）理论上可能触顶，目前未做保活，需要再观察。
- **权限里的 `https://*/*`**：是为了让任意 LLM 接口地址都能用。要发布上架时应收窄成实际用到的域名。
- 图标暂缺（用浏览器默认），上架前补一套 icon。
